# Visit Planner

Personal app for planning family visits: timeline worked back from fixed times, food, sleep, getting back,
check-ins with people, backup plans and notes for next time.

Open it at https://vibes-480.github.io/Visit-Planner/

This repo only holds the app. Your trips, people and places live in the private repo
`Visit-Planner-Data`, which also sends the reminders and runs the roadworks check.
